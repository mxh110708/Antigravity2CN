## 安全边界与修复

旧脚本将用户可写的版本管理器目录放入 PATH，再在 sudo 后使用该 PATH 查找 bash/node，可能使本地低权限写入者在合法安装人员批准提权时取得 root 执行。

本版取消整个自动提权路径：

1. 两个 macOS .command 入口与共用 run_macos.sh 在外部命令和 Node 查找前检查真实 UID 与有效 UID。
2. Node 引擎在导入任何模块之前检查 getuid/geteuid，拒绝真实或有效 root，也拒绝无法确认身份的 macOS 运行环境。
3. 写权限不足时返回失败，不调用 sudo，也不改变目录所有权。
4. 删除引擎中的用户 PATH 扩展及 SUDO_USER 跨用户目录处理。xattr、codesign、open 使用系统绝对路径。
5. 保留普通用户对其可写应用副本进行安装/还原的路径；优先探测用户 Applications 目录。

因此 macOS 用户需使用自己拥有且可写的应用副本。没有新增特权辅助程序，也没有保留“以 sudo 重试”的回退。
